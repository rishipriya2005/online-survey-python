# Online Survey Application (Python)

This is a simple **console-based Online Survey Application** built using **Python**.  
The application allows users to answer survey questions, stores their responses, and displays the results.

---

## 📌 Features

- Multiple-choice survey questions
- User-friendly console interface
- Input validation
- Stores responses in a JSON file
- Displays saved survey results

---

## 🛠 Technologies Used

- Python 3
- JSON (for data storage)
